### 说明

本仓库取自原仓库的 Commit 版本，并在本地进行了底层引擎（解除时间限制与导出握手）的优化与修复。

### 从源码构建

```bash
# 1. 克隆项目到本地
git clone https://github.com/angusdevgo/WeFlow.git
cd WeFlow

# 2. 安装项目依赖
npm install

# 3. 运行应用（开发模式）
npm run dev
```
